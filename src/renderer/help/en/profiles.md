## Do I need several profiles?

Usually not. Profiles separate completely: no report spans two profiles. That fits work and private projects or two employers. If you only want to keep customers apart, use one profile with several [projects](projects.md) or [clients](clients.md).

## Where is my data?

In a single file with the extension `.taktra`, wherever you saved it when creating the profile. There is no account and no server.

## How do I back up my data?

Copy the file, preferably while the profile isn't open. That's all.

## How do I move to a new computer?

Copy the file to the new computer and open it in Taktra there.

## Why does the file have a different name than the profile?

Because the two are independent. If you rename the profile in the [profile settings](#/profile/general), the file name stays the same. Taktra never renames or moves files.

## My profile is shown as unavailable.

Taktra can't find the file, for example because it was moved or a drive is missing. As soon as it's back, everything works again.

## Can I get a deleted profile back?

Yes, from the trash, as long as it hasn't been emptied. When deleting, Taktra only moves the file there.

## What is the sample profile?

An ordinary profile with made-up data for trying things out. Afterwards, simply delete it.
